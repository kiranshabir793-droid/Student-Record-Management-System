# Student Record Management System

## About the Project

This is my first Python project, developed as part of my CodeNova internship. It is a desktop application that helps manage student records using a graphical user interface.

## Technologies Used

* Python
* Tkinter
* SQLite
* Visual Studio Code

## Features

* Add Student
* View Students
* Search Student
* Update Student
* Delete Student
* Student information validation
* GPA and Grade management
* Roll Number management

## Student Information

The system stores:

* Student ID
* Name
* Age
* Gender
* Email
* GPA
* Roll Number
* Grade

## How to Run

1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:
   python main.py
